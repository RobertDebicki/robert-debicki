# robert-debicki

## Po polsku

Strona osobista Roberta Dębickiego (Automation Developer / AI Engineer), zbudowana w Astro jako statyczny HTML. Wersja polska pod `/`, angielska pod `/en/`.

### Uruchomienie lokalnie
```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # wynik w dist/
npm test           # testy jednostkowe
npm run sprawdz:sekrety
```

### Dodawanie treści
Wpisy, projekty i referencje dodaje się z panelu w przeglądarce pod `/admin/` (Sveltia CMS), który zapisuje treść jako pliki w repozytorium. Logowanie tokenem GitHub, instrukcja w `docs/panel-instrukcja.md`.

## In English

Personal website of Robert Dębicki (Automation Developer / AI Engineer), built with Astro as static HTML. Polish at `/`, English at `/en/`.

### Run locally
```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # output in dist/
npm test           # unit tests
npm run sprawdz:sekrety   # secret scan
```

### Adding content
Posts, projects and references are added from a browser panel at `/admin/` (Sveltia CMS), which saves content as files in the repository. Sign in with a GitHub token; instructions (in Polish) in `docs/panel-instrukcja.md`.
